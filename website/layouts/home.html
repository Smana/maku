Open cloud-native stack, zero vendor lock-in

Bring your own Kubernetes cluster, OIDC identity provider (Okta, Entra ID, Keycloak, ZITADEL), OpenAI- or Anthropic-compatible model providers (SaaS or self-hosted), and GitOps controller. Data-class routing keeps private repositories strictly on authorized providers, backed by PostgreSQL 16+ RLS and immutable audit triggers.

Threat model & guarantees →

Sandboxed runs with hard external budgets

Each agent runs in its own gVisor pod behind a default-deny network policy and scoped short-lived GitHub App tokens—a reviewer cannot push and an implementer cannot merge. Per-run, per-person, and per-task USD caps are enforced at the model gateway outside the sandbox, alongside a single emergency kill switch.

Model gateway & budgets →

Collaborative rooms, complementary to local agents

Run maku setup once to register the MCP server and handoff skill for Claude Code, OpenCode, Cursor, Codex, Copilot, and Gemini—or file from Slack and GitHub. Follow live tool calls in the Web UI or CLI, steer a run mid-flight, approve sensitive actions from raw diffs, or fork a room from any event.

CLI & MCP handoff →

Earned auto-merge & scheduled upkeep routines

Every merge class begins in shadow mode so humans review while Maku logs its verdicts. Promote proven classes to live in GitOps with daily caps and an automatic post-merge revert breaker, and schedule recurring hygiene (dead-links, renovate-red, doc-drift, custom CRDs) inside an isolated upkeep budget.
